## How To Contribute

While the project is in early development, we are only accepting contributions from core maintainers.

This repository holds generated code. The source of truth is the main
[loonfs repository](https://github.com/loonfs/loonfs): the SDK is generated
from its OpenAPI documents, and the handwritten pieces live under its `sdk/`
directory. Regeneration overwrites files here, so we cannot take pull requests
in this repository. Please report problems as issues on the main repository.
